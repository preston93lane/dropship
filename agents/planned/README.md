# Planned agents (not applied yet)

These are specified but intentionally **not** picked up by `ant apply agents` (they sit in a
subdirectory and are not referenced by any deployment). Move a file up to `agents/`, add it to a
coordinator's roster or give it a deployment, and run `ant apply` when you reach its roadmap phase.

| Agent | Phase | Why later |
|---|---|---|
| `affiliate-manager` | 7 | TikTok Shop affiliate/creator outreach is the highest-ROI TikTok Shop channel, but only after a product is proven and listed on TikTok Shop with US stock. |
| `support-agent` | 7 | Customer email/chat triage (order status, returns). Worth it at roughly 20+ orders/day; before that, Shopify Inbox + a human is cheaper. |
