# Creative patterns

## Demo-led first 1.5s beats talking-head intros for gadget products
- Confidence: prior · Action: lead with the product working or the problem, not a face saying hello

## Native beats polished
- Confidence: prior · Action: phone-shot look, natural light, captions, fast cuts (every 1-2.5s)

## Diversity over volume
- Confidence: prior · Action: each batch spans >= 3 of 5 dimensions (format, angle, hook, spokesperson, visual world)

## Motion-graphic showcase is the cheapest useful concept
- Confidence: prior · Action: include one in every initial batch
